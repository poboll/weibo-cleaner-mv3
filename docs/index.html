Chrome / Arc / Edge 等 Chromium 浏览器·原 ID 移植，旧规则自动延续

它还是那个「眼不见心不烦」

过滤逻辑一行未改，全部能力与 2020 年的 2.6.1 一致。

🚫 深度屏蔽

关键词、用户、来源、链接微博与正则匹配，把时间线上一切你不愿看到的内容清出去。

🧹 版面净化

隐藏广告、推荐与热门模块，还你一条干净的信息流。

🎛 可视化规则

扩展设置页逐项配置，规则支持导入导出；本移植版沿用原扩展 ID，旧规则自动回归。

🧬 MV3 合规

仅重写打包清单：Manifest 2→3、补充搜索页匹配、document_start 注入；脚本本体零修改。

一分钟安装

与所有解压式扩展相同的安装流程。

下载解压到 Releases 下载 zip，解压到长期保留的目录。
打开扩展管理页地址栏输入 chrome://extensions，打开「开发者模式」。
加载扩展点「加载已解压的扩展程序」，选择解压出的文件夹。
打开微博进入 weibo.com，在扩展设置里配置你的过滤规则，或者什么也不用做——旧规则会自动回来。
